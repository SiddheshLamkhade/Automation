task 1 — home page verification

Element : Logo image (alt text)
Locator : By.cssSelector("#logo img")
Reason : selects image inside logo section

Element : H3 heading
Locator : By.xpath("//h3")
Reason : directly finds the h3 heading

Element : Navigation links (list)
Locator : By.cssSelector("nav ul li a")
Reason : gets all links from navigation menu

task 2 — about us

Element : About Us link (header)
Locator : By.linkText("About Us")
Reason : uses visible link text

Element : Page heading (h1)
Locator : By.cssSelector("#page-content > h1")
Reason : selects main heading of page

Element : Breadcrumb links (list)
Locator : By.cssSelector(".breadcrumb a")
Reason : gets all breadcrumb links

Element : Paragraph content
Locator : By.cssSelector("#page-content > div.wysiwyg > p")
Reason : selects paragraph inside content area

task 3 — catalog page

Element : Catalog link
Locator : By.linkText("Catalog")
Reason : uses visible link text

Element : Page heading (h1)
Locator : By.cssSelector("#page-content > h1")
Reason : selects page heading

Element : Product titles (list)
Locator : By.cssSelector("section.product-grid h3")
Reason : gets all product names

Element : Sold Out badge
Locator : By.xpath("//span[contains(text(),'Sold Out')]")
Reason : finds text “Sold Out”

Element : Sold Out product name
Locator : By.xpath("./ancestor::div[contains(@class,'product-card')]//a")
Reason : moves from badge to product name

Element : Grey jacket link
Locator : By.partialLinkText("Grey")
Reason : matches part of product name

task 4 — product detail page

Element : Grey jacket product link
Locator : By.cssSelector("a[href*='grey-jacket']")
Reason : matches link using part of URL

Element : Product name (h1)
Locator : By.cssSelector("h1")
Reason : gets main product title

Element : Product price
Locator : By.cssSelector("#product-price > span")
Reason : selects price element

Element : Breadcrumb links (list)
Locator : By.tagName("a")
Reason : gets all links on page

Element : Add to cart button
Locator : By.xpath("//*[@id='add']")
Reason : finds button using id

task 6 — header links & cart

Reason : matches cart text (count may change)
